# ¿Para qué sirve?
Este es un bot de Discord que sirve para almacenar y clasificar imágenes, con los comandos $save y $analyze, respectivamente.

## $save
Este comando sirve para guardar todos los archivos adjuntos dentro de la aplicación.

## $analyze
Este comando sirve para analizar las imágenes enviadas y clasificarlas si son abejas reales o imitadores. Ten en cuenta que los archivos enviados se guardan.

## $show
Este comando muestra todos los archivos que fueron almacenados o analizados.
